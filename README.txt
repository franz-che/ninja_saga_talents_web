# Ninja Saga Talents Web Database

Open `index.html` in a browser. This is a static, offline-friendly database generated from the uploaded workbook `Ninja Saga Talents(1).xlsx`.

Included:
- 69 talents (37 Extreme, 32 Secret)
- 318 extracted skill screenshots
- Passive-stat table from the workbook Home sheet
- Talent search/filtering
- Talent detail drawer with screenshots
- Side-by-side comparison for up to four talents
- Dev build references supplied in chat
- Emblem-only and PvP-speculation tags supplied in chat

The app intentionally does not score or rank talents. Active temporary stat boosts are kept out of the passive-stat table.
