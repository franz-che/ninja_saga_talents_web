# Ninja Saga Online Talents Web Database


Included:
- 69 talents (37 Extreme, 32 Secret)
- 318 extracted skill screenshots
- Passive-stat table from the workbook Home sheet
- Character Builder with profile stats, adjustable element values, and selected talents with passive stats
- Talent search/filtering
- Talent details with screenshots
- Side-by-side comparison for up to four talents

Scripts:
- `data.js` contains the talent data.
- `app.js` handles browsing, passive stats, comparison, and talent details.
- `character-builder.js` handles built talents and element point allocation.

The app intentionally does not score or rank talents. *Active temporary stat boosts* are kept out of the passive-stat table.
